# v0.9.10 external outside provider validation

The completed [geometry and roughness follow-up](v0.9.10_geometry_roughness.md)
adds reference-area diagnostics and further regression checks. The counts
below retain the original external-provider implementation receipt.

The generic dry provider boundary has synthetic integration coverage for
independent thermal/hydraulic selection, applicability, unchanged native
geometry, physical film input to the existing 2D fin solver, effective h/U/UA,
Rating and Simulation, warnings/provenance and rejection of invalid results.
Pressure tests cover all four scopes, signed static recovery, one acceleration
addition for irreversible loss and rejection of overlapping local paths.

The existing Zhao source tests retain their numerical snapshots and geometry,
orientation, source-domain and correction guards. A hydraulic guard-order
regression found during verification was corrected by placing early geometry
validation on the selected Zhao model. Independent external execution never
calls that model's applicability checks.

The final receipt is [v0.9.10_test_summary.json](v0.9.10_test_summary.json).
It records **1326 distinct passing public tests**: 84 provider/guard tests and
1297 selected existing regressions (55 tests overlap). These cover dry outside,
geometry, resistance-network, internal, pressure, topology, Rating and fin
regressions listed in [the public selection](v0.9.10_public_test_selection.json).
Selection is explicit so numerical checks can be reproduced without unrelated
wet-model research cases. Tests use public synthetic data only.

Run the selected existing tests plus the new external-provider tests:

```python
import json
import pytest

with open('docs/validation/v0.9.10_public_test_selection.json') as stream:
    selected = json.load(stream)
raise SystemExit(pytest.main(['-q', *selected,
    'core/tests/external_outside_provider_test.py']))
```

Verification used Python 3.12.8 and CoolProp 6.6.0. Attempted full-suite runs are
not claimed as passes: older wet-gas tests encounter a mixture h,p flash error
in that backend and historical tests with disabled timeouts can run unbounded.
The same flash error and unrelated wet-property golden differences were
reproduced on unchanged main. Existing physical correlations were not changed
to accommodate those environment limits.

Runtime, source declaration and installed distribution metadata agree on
0.9.10; wheel inspection checks for the expected public modules and absence of
external implementations/data. The self-contained synthetic example runs
Simulation and Rating through ordinary public entry points.

This evidence validates API integration and regression behaviour. **No public
SHIFTED correlation is introduced or experimentally validated.** An external
provider's applicability, reference basis, provenance and engineering
limitations remain its own responsibility.
