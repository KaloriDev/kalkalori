## Model and engine integration

`Zhao2017AirsideModel` and immutable result/flow/factor types reside in
`core/heat_transfer/finned_ellipse_airside.py`. They reuse actual tube and fin
geometry, exact outer perimeter, installed frontal area and physical surface.
They neither duplicate geometry in source presets nor use a circular bank's
minimum flow area. The mathematical inference de=4A/P is explicitly labeled,
not a claim that any circular constitutive correlation applies to the ellipse.

Normal outside dispatch selects this model for rectangular-finned ellipses.
Circular heat-transfer/pressure providers cannot be selected for this surface.
The normal thermal state obtains h_film, applies an optional correction, solves
`ThinPlateFinEfficiency2D(h_film)` and constructs the common resistance network.
This repeats at relevant iterated states, reusing the existing bounded fin
caches. The physical coefficient is unchanged by eta; G_out=h_film*A_effective.

`AirsideCorrectionProvider.correct(base_result, *, bundle, props)` is the one
neutral injection point. Positive multipliers/replacements act independently
on physical h before eta and on final pressure estimate. Baseline and corrected
values/provenance remain available; no provider is identity, and invalid
responses/exceptions propagate without fallback. There is no discovery table,
vendor registry or alternate whole-core solver.

The initial validation used explicit laminar H1/confocal controls. Current
v0.9.2 normal dispatch is automatic, with the same synthetic laminar result;
see [API cleanup](../elliptical_api_v092.md). General contours use numerical
wall conduction. Width is now transverse and height streamwise; the physical
source envelope and numerical regression values below are preserved.

### Pressure semantics

The model returns `DeltaP=f*(rho*u_m**2/2)*(A_physical/Aa)` at the normal
arithmetic-temperature mean state. Inlet/midpoint/outlet point properties and
diagnostics are retained. It is not Simpson integration of a newly assumed
row-local pressure law. N is already in the correlation and installed area;
no extra N multiplier appears. Physical, not eta-reduced, outside area is used.

`Zhao2017BankHydraulicResult` reports a finite source-domain inlet-to-outlet
estimate with `validated_bank_irreversible=False`. No separately computed
acceleration, inlet/exit or duct loss is added. A separate
`SourceDomainPressureEstimateResult` supplies compatibility totals without
creating an irreversible `PressureDropStageResult`. Unknown pressure
components are not certified as zero. Explicit irreversible local-path
aggregation rejects this unresolved bank estimate. Legacy `dp_drag` aliases
the source estimate and must be interpreted with its metadata.

The package's roughly 735 Pa versus 404.49 Pa nine-row comparison remains an
unresolved normalization discrepancy, not a fitted multiplier or an
experimental validation fixture. A production user must retain that caveat
even when the dimensionless inputs are inside the reported source interval.
