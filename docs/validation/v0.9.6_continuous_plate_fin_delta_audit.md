## Targeted findings

- Finite integer-sheet/collar ledger distinguishes exposed tube and collar
  cylinders, sheet faces, inlet/outlet edges, lips and sealed boundaries.
  Actual finite transverse/diagonal passages determine the free-flow area;
  source face/cylinder area remains distinct from physical gross area.
- Schmidt efficiency retains both pitches and one-face terminal-sheet
  weighting. Effective area includes primary cylinders and efficiency-weighted
  faces; adiabatic edges/lips remain excluded from conductance. Overall
  efficiency uses physical gross area. Zero-HTC and high-conductivity limits
  and correction-before-efficiency behavior pass existing tests.
- The resistance network uses the corrected source HTC once, adds inside and
  outside fouling on their declared areas and retains core-wall resistance.
  Empirically included contact is not penalized a second time. UA and energy
  reconstruction pass Rating/Simulation and supported internal-steam tests.
- Compact-HX friction is not treated as a Darcy factor. Core pressure uses
  the declared area/mass-flux basis and harmonic endpoint density; correction
  acts only on positive friction. The signed density term stays separate.
  Unresolved source estimates retain their pressure basis and reject local
  irreversible-loss aggregation.
- Explicit opt-in, dry-air/source-domain guards, no AUTO/bare/individual-fin
  substitution, unsupported wet-provider rejection and source warnings remain.
  No private KON/PVT dependency was introduced in the public-core delta.
  Existing upstream attribution, MIT notice and package-data inclusion remain.
- One intentional legacy-provider change was already present in `57a8d75`:
  Robinson–Briggs permits 1–3 rows with an unvalidated short-bank warning and
  actual-row scaling. Frozen >=4-row behavior and other applicability warnings
  are tested. Other existing provider selections/defaults remain unchanged,
  including the Elmahdy–Mitalas wet default.

No clear implementation defect or critical API blocker was found within this
delta scope. No numerical code, tolerance or correlation was changed during
closure. Documentation now records validation status and marks the historical
merge/PR hold as superseded by the user's final integration instructions;
source/physical-validation gates remain open. README wording also reflects the
intentional Robinson–Briggs change.

## Remaining limitations and deferred validation

Implementation is complete within the explicit experimental scope. Automated
software verification does not close Wang source gates B01–B03, experimental
checkpoints B04 or finite-cell/flow validation B05. Source status remains
`SOURCE_PARTIALLY_CLOSED` / `SYNTHETIC_ARITHMETIC_ONLY`; strict source mode
rejects the unresolved domain. Industrial tube OD 25–50 mm is unsupported.

Finite edge-cell conduction, inter-zone common-sheet conduction and detailed
surface temperature extrema remain unresolved. Wet sheets/wet DP and two-phase
tube-side DP remain unsupported. Some three-zone inputs can still hit the
existing steam zone-allocation convergence guard; no tolerance was relaxed.
Pressure entry/core/exit interpretation remains unvalidated.

Manual validation against representative industrial exchanger cases and
independent experimental reference data **has not been performed**. Thermal
and hydraulic prediction accuracy remains subject to future validation.
Deferred work, without implementation in this closure:

- Manual industrial live-case validation.
- Independent experimental validation of thermal and hydraulic correlations.
- Additional continuous-fin reference cases as experimental data become available.

These remain follow-up validation tasks for the guarded experimental feature,
not blockers to merging sound software with the limitations documented.
Package version remains 0.9.5; no release, package publication or tag is created.
